# PalAuraBars

Аддон для **World of Warcraft 3.3.5a (WotLK)** — показывает, **какая аура активна
у каждого паладина** в группе и рейде.

![PalAuraBars](PalAuraBars.jpg)

Для каждой реально включённой ауры выводится строка с её иконкой и никами всех паладинов,
которые её **активировали**. Паладины без активной ауры показываются отдельной строкой
«Без ауры».

## Как это выглядит

Представь: у паладина A включена «Аура воздаяния», у B и C — «Аура сосредоточенности».
Аддон покажет две строки:

```
[иконка] A
[иконка] B, C
```

Сразу видно, у кого какая аура, и кто из паладинов включил одинаковую.

## Возможности

- Отслеживает все ауры паладина: самоотверженности, воздаяния, сосредоточенности,
  сопротивления (тьме / магии льда / магии огня), воина Света.
- Правильно определяет, кто включил ауру — чужие ауры не подмешиваются.
- Цвет ников: белый, классовый или по цвету ауры.
- Настройка размера, отступов, шрифта и цвета полоски.
- Перетаскивание мышью, позиция сохраняется.
- Русский и английский (по локали клиента).

## Установка

1. Скачай папку `PalAuraBars`.
2. Помести в `<путь к WoW>\Interface\AddOns\` — должно получиться
   `Interface\AddOns\PalAuraBars\`.
3. Перезапусти клиент или выполни `/reload`.

## Команды

| Команда | Действие |
|---|---|
| `/pa` | открыть / закрыть окно настроек |
| `/pa unlock` | разблокировать позицию (перетаскивание мышью) |
| `/pa lock` | закрепить позицию |
| `/pa reset` | сбросить настройки |

## Совместимость

- Клиент: WoW 3.3.5a (WotLK).
- Работает и в одиночку, и в группе, и в рейде.
